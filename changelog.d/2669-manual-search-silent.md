### Fixed
- **Search buttons no longer report success when automatic grabbing is off** (#2669): the global auto grab switch stops every search at one chokepoint, including the ones you start by hand, but the author page "Search wanted" and the Wanted page bulk Search had already answered `{"ok":true}` by the time the fan out hit it. The button flashed, the selection cleared, and the only trace was an `auto-grab disabled globally, skipping search` line in the server log. Those three bulk search actions now refuse up front, with a per id `auto_grab_disabled` code and a message that names the setting to change, and the UI shows it and keeps your selection so you can retry after flipping the switch. Nothing else about the switch changed: the scheduled sweep, discovery and the per book Search Indexers page all behave exactly as before. The Auto grab hint in Settings promised the opposite of what the code did, and now describes what actually happens. Thanks to ThatDeltaGuy for the report and the log lines.
